选择笔记接口

先选择要使用的接口，再进入对应页面。写入接口只提交任务，请先启动消费者，稍后再用 id 查询。

新增笔记

POST /note/add。需要登录。任务进入队列后异步保存，接口不返回新 id。

查询笔记

输入账号名字，会列出该账号全部笔记，并用笔记 id 调用 GET /note/read/{id} 显示。输入笔记 title，会直接按匹配到的笔记 id 显示内容。已登录时，点「查询自己笔记」可直接列出当前账号新增的全部笔记。

修改笔记

PUT /note/update/{note_id}。需要登录，只能改自己的笔记。

删除笔记

DELETE /note/delete/{note_id}。需要登录，只能删自己的笔记。

与 AI 聊天

POST /chat。同一 session_id 会带上历史。问「查询笔记 id 为 1 的内容」时，后端会调用工具 query_note_by_id。

接口与后台任务

文档地址：http://127.0.0.1:8000/docs

  • POST /user/register　参数 username、password
  • POST /user/login　参数 username、password，返回 token
  • POST /note/add　参数 title、content、token，消息入队 action=add
  • GET /note/find　参数 keyword，按账号名或笔记 title 返回笔记 id
  • GET /note/read/{note_id}　先读 Redis，没有再查 MySQL 并加锁
  • PUT /note/update/{note_id}　参数 title、content、token，入队后删除该笔记缓存
  • DELETE /note/delete/{note_id}　参数 token，入队后删除该笔记缓存
  • POST /chat　参数 question、session_id，可触发工具 query_note_by_id

消费者 notes-zhixing.py 监听队列 note_task_queue。它按 msg_id 做幂等，然后执行新增、修改或删除，并写入 msg_record。前端没有单独的消费者接口，写操作成功只表示消息已提交。
